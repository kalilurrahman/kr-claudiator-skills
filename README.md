## Usage

Place a skill directory under `/mnt/skills/` (or your Claude Code skills directory) and
reference it in your Claude system prompt or tool configuration.

Each SKILL.md contains:
- Frontmatter (name, description, argument-hint, allowed-tools)
- Step-by-step process
- Production-ready output templates with working code examples
- Worked examples with realistic scenarios
- Anti-patterns table
- 10 rules

## Quality bar

The gold-standard rubric for what a finished skill must contain lives in
[docs/premium/02-CONTENT-BLUEPRINT.md](./docs/premium/02-CONTENT-BLUEPRINT.md).
Skills under 100 lines are considered stubs and are queued for rebuild or deletion
(`scripts/audit_skills.py` lists them).
